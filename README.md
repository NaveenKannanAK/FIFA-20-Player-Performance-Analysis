# FIFA 20 Player Data Analysis

## Project Information
- **Project:** FIFA 20 Player Data Analysis
- **Project Code:** PRCP-1004
- **Domain:** Data Analysis and Machine Learning
- **Tools:** Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Project Overview
This project analyzes FIFA 20 player data to explore player characteristics, football skills, country-wise player distribution, age-related overall ratings, and positional wage differences.

## Tasks Completed
1. Complete Exploratory Data Analysis (EDA).
2. Football skill analysis and player clustering.
3. Top 10 countries based on player count.
4. Analysis of overall rating against player age.
5. Wage comparison among ST, RW, and LW positions.
6. Comparison of clustering algorithms.
7. Documentation of challenges, findings, and conclusions.

## Machine Learning
Clustering algorithms evaluated:
- K-Means
- Agglomerative Clustering
- Gaussian Mixture Model (GMM)

K-Means was selected based on the overall comparison of clustering metrics and execution time.

## Project Files
- `FIFA_20_Player_Analysis_FINAL_VERIFIED.ipynb` – Main analysis notebook.
- `players_20.csv` – Dataset.
- `README.md` – Project documentation.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries: pandas, numpy, matplotlib, seaborn, and scikit-learn.
3. Keep the dataset and notebook in the same folder.
4. Open the notebook in Jupyter.
5. Run all cells from beginning to end.

## Conclusion
The project explores FIFA 20 player data through exploratory analysis and unsupervised learning, identifying broad player skill profiles and examining country, age, and positional wage patterns.
